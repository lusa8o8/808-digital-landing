# 808 Digital Systems

  Landing page for **Eight Zero Eight Digital Systems** — an independent software studio based in Zambia building thoughtful digital products for modern life and work.

  ## Products

  - **Samm** — AI-assisted marketing workflow and approvals for lean teams
  - **D8** — A lifestyle and planning ecosystem for discovering venues, planning outings, and coordinating experiences

  ## Stack

  React · Vite · TypeScript · Tailwind CSS · Framer Motion · shadcn/ui

  ## Pages

  - `/` — Home
  - `/privacy` — Privacy Policy
  - `/terms` — Terms of Use
  - `/data-deletion` — Data Deletion

  ## Getting started

  ```bash
  pnpm install
  pnpm --filter @workspace/808-landing dev
  ```
